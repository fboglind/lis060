# lis060 - MyNLTK: A NLP library
A small library of NLP tools, built from scratch, with numpy as the only external dependency. 

Partof examination in the course LIS060 (Natural Language Processing), AI and Language program, Stockholm University, Spring 2025.    
Includes:
- Tokenizer
- Byte Pair Encoder
- N-Gram model
- N-Fold Cross Validator
- Perceptron/Feature Based Morphological Analyzer
- Structured Perceptron/Named Entity Recognition
- ...and more
